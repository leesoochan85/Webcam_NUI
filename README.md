# Webcam NUI · 첫 실행 버전

웹캠에서 한 손을 추적해 Windows 마우스와 창 전환, 캡처 도구를 조작합니다.
MediaPipe의 사전 학습 손 검출·랜드마크 모델을 사용하며, 손모양과 연속 동작은 기하 계산과 상태 머신으로 판별합니다. 별도 사용자 데이터 학습 과정은 없습니다.

## 1. 실행 순서

1. ZIP 전체를 `C:\Projects\webcam_nui` 같은 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 않습니다.
2. **Python 3.12 또는 3.11의 Windows 64비트 버전**과 Python Launcher를 설치합니다. 이미 있다면 그대로 사용합니다.
3. `setup_windows.bat`을 실행합니다. 전용 `.venv`를 만들고 패키지를 설치합니다. 패키지 설치에 인터넷이 필요합니다.
4. `start_preview.bat`을 실행합니다. 손 인식과 제스처 상태, 미니 화면의 커서를 먼저 확인합니다. 이 모드는 운영체제에 마우스·키보드 입력을 보내지 않습니다.
5. 확인 창을 닫고 `start_nui.bat`을 실행합니다. **PAUSED 상태로 시작합니다. F8을 눌러 실제 조작을 켭니다.**
6. **F8: 켜기/일시정지, F10: 어느 창에서든 프로그램 종료.** 미리보기 창에 키보드 초점이 있을 때는 P로 전환, Q 또는 Esc로 종료할 수도 있습니다.

이 프로젝트는 자동매매 프로그램의 키움용 Python 3.9 32비트 환경과 별개로 실행합니다.

## 2. 제스처

| 기능 | 손동작 | 동작 조건 |
|---|---|---|
| 커서 이동 | 검지만 펴서 이동 | 엄지는 편안하게 두고 중지·약지·소지는 접기 |
| 좌클릭 | 엄지·검지를 짧게 붙였다 떼기 | 떼면서 검지만 편 상태로 돌아오기 |
| 드래그 | 엄지·검지 핀치 유지 후 이동 | 약 0.28초 유지하거나 커서를 14픽셀 이상 이동하면 누름, 핀치를 풀면 해제 |
| 우클릭 | 검지를 편 채 엄지·중지 핀치 | 약지·소지는 접기. 유지 중 한 번만 실행 |
| 스크롤 | 검지·중지를 V로 편 채 위아래 이동 | 나머지 손가락은 접기. 커서는 고정 |
| 창 전환 진입 | 다섯 손가락을 편 손바닥 유지 | 약 0.8초 후 Alt+Tab 열기 |
| 이전/다음 창 | 창 전환 중 편 손바닥 좌우 이동 | 한 번에 일정 거리 이동할 때마다 한 칸 이동 |
| 창 선택 | 창 전환 중 엄지·검지 핀치 | Alt 해제. 일반 클릭은 실행하지 않음 |
| 창 전환 종료 | 창 전환 중 손이 카메라에서 사라짐 | 약 0.35초 후 Alt 해제. 현재 강조된 창이 선택됨 |
| 캡처 도구 | **주먹 → 펴기 → 주먹 → 펴기** | 약 2.8초 이내. Win+Shift+S로 Windows 캡처 오버레이 열기 |
| 캡처 영역 | 오버레이에서 검지 이동 → 핀치 유지·드래그 → 풀기 | Windows 사각형 캡처 모드 사용. 이미지 저장은 Windows 캡처 도구에서 처리 |
| NUI 켜기/끄기 | 소지만 편 상태 약 1.2초 유지 | 유지 중에는 한 번만 전환. F8도 동일 기능 |

**이전 대화에서 정한 기능:** 검지 이동, 핀치·드래그, 캡처 도구만 열기, 편 손바닥 창 전환, 선택·손 이탈 시 종료, 제스처 충돌 최소화, 화면 끝 재진입 처리.

**이번 구현에서 정한 기본값:** 우클릭 손모양, V 스크롤, 소지 유지 전환, 각 유지 시간과 감도. 실제 웹캠에서 확인하며 `config.json`으로 조정합니다. 최신 대화의 보이지 않는 세부 규칙까지 확인했다는 의미는 아닙니다.

## 3. 화면과 조작 요령

- 웹캠 영상은 기본적으로 거울처럼 좌우 반전됩니다. 화면에서 손을 오른쪽으로 움직이면 커서도 오른쪽으로 움직입니다.
- 영상의 안쪽 사각형이 커서 매핑 영역입니다. 카메라 화면 전체 끝까지 손을 밀지 않아도 모니터 끝에 도달하도록 가장자리 여백을 둡니다.
- 검지 끝의 노란 원은 추적 위치, 오른쪽 아래 작은 사각형의 노란 점은 모니터에 대응하는 커서 위치입니다. LIVE 모드에서는 Windows 커서도 이동합니다.
- 한 손과 손가락 전체가 보이도록 사용합니다. 손바닥을 너무 옆으로 돌리면 손가락이 겹치므로 손바닥 면을 카메라 쪽으로 보여 주면서 좌우 이동합니다.
- 제스처를 바꿀 때 약 0.07초 확인 시간을 둡니다. 손모양을 유지하면서 자연스럽게 바꿔 주세요.
- 시작 상태/일시정지 해제/추적 복귀 후에는 검지만 펴서 기준 위치를 먼저 잡고 핀치를 시작합니다.

### 화면 끝에서 손이 사라졌을 때

1. 커서 이동 중 손이 끝으로 나가면 마지막 위치를 유지합니다. 이미 매핑 영역 밖으로 이동했다면 커서를 해당 화면 끝에 고정합니다.
2. 최대 약 3초간 같은 방향의 카메라 가장자리에서 검지가 다시 들어오기를 기다립니다. 다른 방향으로 들어오면 커서를 고정합니다.
3. 같은 쪽으로 들어오면 기존 커서 위치에서 부드럽게 다시 이동합니다. 3초가 지나면 다른 위치에서도 부드럽게 다시 잡습니다.
4. 화면 중앙에서 가려진 경우에는 가장자리 조건을 요구하지 않습니다.

이는 실제 이탈 방향을 별도 모델로 예측하는 기능이 아니라 **마지막 검지 위치가 가까웠던 경계를 기준으로 하는 구현**입니다.

## 4. 제스처 충돌 처리

- 주먹으로 캡처 패턴을 시작하면 이어지는 편 손바닥은 패턴 입력으로 먼저 소비합니다. 이때 Alt+Tab으로 진입하지 않습니다.
- 캡처 패턴이 시간 초과되면 손모양을 바꾼 뒤 다시 편 손바닥을 보여야 창 전환으로 진입합니다.
- 캡처 오버레이를 연 후에는 영역 선택용 포인터·핀치만 사용하며, Alt+Tab·우클릭·스크롤을 억제합니다. 드래그 완료 또는 20초 후 이 내부 모드가 끝납니다. 20초 제한은 Windows 오버레이를 강제로 닫는 기능은 아닙니다.
- 창 전환 모드의 핀치는 선택만 수행합니다. 그 핀치를 유지한 채 일반 클릭·드래그가 이어지지 않습니다.
- 핀치 중 손을 놓치면 눌린 왼쪽 버튼을 즉시 해제합니다. 짧은 핀치 중 추적이 끊겨도 클릭으로 처리하지 않습니다.
- 카메라 읽기 실패, 정상 종료, 예외 발생 시 누른 키·버튼을 해제합니다. 프레임 처리가 약 1.5초 이상 멈추면 별도 감시 스레드도 입력을 해제하고 조작을 중단합니다. 프로세스 강제 종료·OS 정지까지 보장하지는 않습니다.

## 5. 설정 조정

프로그램을 종료한 뒤 `config.json`을 수정하고 다시 실행합니다.

| 설정 | 기본값 | 조정 방법 |
|---|---:|---|
| `camera_index` | 0 | 다른 웹캠이면 1, 2 순서로 확인 |
| `mirror` | true | 거울 반전 사용 여부 |
| `pinch_close` / `pinch_open` | 0.30 / 0.48 | 손바닥 크기로 정규화한 손끝 거리. 잘 안 붙으면 close를 조금 늘리기. open은 close보다 크게 유지 |
| `drag_hold` | 0.28 | 길게 눌러 드래그를 시작하는 시간(초) |
| `drag_distance_px` | 14 | 핀치 후 이 거리 이상 움직이면 일찍 드래그 시작 |
| `alt_hold` | 0.8 | 편 손바닥으로 창 전환에 진입하는 시간 |
| `alt_step_distance` | 0.12 | 창 한 칸 이동에 필요한 카메라 폭 비율 |
| `capture_timeout` | 2.8 | 주먹·펴기 두 번 패턴의 전체 허용 시간 |
| `edge_margin` | 0.12 | 커서 매핑 여백. 더 크면 작은 손 이동으로 모니터 전체 이동 |
| `smoothing_tau` | 0.045 | 커서 보정 시간. 늘리면 덜 떨리지만 느려짐 |
| `scroll_step` | 0.035 | 스크롤 한 눈금에 필요한 세로 이동 비율 |
| `scroll_invert` | false | 스크롤 방향 반전 |

`start_preview.bat --camera 1`처럼 카메라 번호만 임시로 바꿀 수도 있습니다.

## 6. 파일 역할

| 파일 | 역할 |
|---|---|
| `main.py` | 웹캠 읽기, MediaPipe 추론, 화면, 단축키, 종료 처리 |
| `nui/gestures.py` | 21개 랜드마크의 각도·거리로 손모양 판별 |
| `nui/engine.py` | 시간 조건, 동작 우선순위, 클릭·드래그·캡처·창 전환 상태 |
| `nui/pointer.py` | 커서 좌표 매핑, 떨림 보정, 화면 끝 재진입 |
| `nui/backend.py` | Windows 입력과 입력 없는 미리보기 분리 |
| `nui/watchdog.py` | 프레임 지연 시 누른 입력 해제 |
| `config.json` | 카메라·감도·시간 설정 |
| `models/hand_landmarker.task` | Google 공식 사전 학습 모델 |
| `download_model.py` | 모델 무결성 구조 검사, 없거나 손상됐을 때 공식 URL에서 받기 |
| `tests/` | 카메라 없이 제스처 처리·좌표·Windows 입력 구조 검증 |
| `logs/nui.log` | 상태 전환·오류 로그. 실행할 때 생성 |
| `VALIDATION.md` | 검증 결과와 실제 PC에서 확인할 항목 |

영상 저장·스크린샷 자동 저장·학습 데이터 수집 기능은 구현하지 않았습니다. 앱 코드는 프레임을 웹 API로 전송하지 않습니다. MediaPipe 자체의 성능 지표 처리 정책은 Google 공식 안내를 참고하세요.

## 7. 오류가 생기면

| 증상 | 확인할 부분 |
|---|---|
| Python이 없다고 나옴 | CMD에서 `py -0p`로 설치 목록 확인. Python 3.12/3.11 64비트와 Launcher 필요 |
| `.venv`가 잘못된 Python을 사용 | 이 프로젝트 안의 `.venv` 폴더만 지우고 설치 배치 파일 재실행 |
| 웹캠을 못 엶 | Zoom/카메라 앱 종료, Windows 설정의 데스크톱 앱 카메라 권한, 카메라 번호 확인 |
| 모델이 없거나 손상됨 | `setup_windows.bat` 재실행 또는 `.venv\Scripts\python.exe download_model.py --force` |
| `DLL load failed` | Windows x64용 Microsoft Visual C++ 재배포 패키지 설치 여부와 Python 64비트 확인 |
| 관리자 권한 앱에서 조작 안 됨 | Windows 입력 권한 차이로 SendInput이 차단될 수 있음. 일반 권한 메모장부터 테스트 |
| 손은 잡히는데 클릭 안 됨 | LIVE/ON 상태인지 확인. 검지만 펴기 → 엄지·검지 핀치 → 검지만 펴기로 돌아오기 |
| 캡처 중 도구가 취소됨 | 손가락이 가려지면 누른 버튼이 풀릴 수 있음. 손 전체가 보이게 다시 시도 |
| `Input watchdog` 오류 | 프레임 지연으로 중단됨. 재실행하고 카메라 해상도를 낮추거나 다른 앱 부하 확인 |

## 8. 범위와 출처

기본 모니터 1대, 한 손 사용을 대상으로 합니다. 다중 모니터 이동, 개별 창을 직접 가리켜 선택하는 UI, 직접 학습한 제스처 모델은 포함하지 않습니다. 창은 Windows 기본 Alt+Tab 목록을 좌우로 넘겨 선택합니다. 장치·조명·손 가림에 따른 인식률과 실제 Windows 조작은 사용자 PC에서 검증해야 합니다.

개발 기준일: **2026-10-29**. 주요 의존성은 재현 가능한 기준 버전(MediaPipe 0.10.35, OpenCV 4.11.0.86, NumPy 1.26.4)으로 고정했습니다. 최신 버전이라는 의미는 아닙니다. 추후 패키지·Windows 변경 시 설치 결과가 달라질 수 있습니다.
